# 蕾塞 Reze · Codex 宠物下载版

这是以《电锯人》角色蕾塞为原型制作的非官方同人 Codex 宠物。本仓库提供目前的**拿花修订版**：鼠标悬停时，宠物站定拿花、微笑并眨眼。

## 下载和使用

在仓库页面选择 **Code → Download ZIP**。解压后，将 `pet.json` 和 `spritesheet.webp` 放在同一个 Codex 宠物目录中，再在宠物选择器中选用「蕾塞 Reze」。

## 现有版本

| 制作版本 | 特点 | 公开下载 |
| --- | --- | --- |
| 初版 | 悬停动作是跳跃 | 未在本仓库发布 |
| 拿花修订版 | 悬停时站定拿花、微笑和眨眼 | 本仓库提供 |

两个版本的 `spriteVersionNumber` 都是 2；这个数字指 Codex 宠物文件格式，不代表制作版本数。
